# Manual test results template

Copy this file once per tester and test machine, and fill it in while you follow
[manual-test-checklist.md](manual-test-checklist.md). Each step id below is the id of a step in the checklist.

Send it back in one of two ways:

1. Commit it as `docs/manual-test-results/<date>-<name>.md`, for example
   `docs/manual-test-results/2026-10-15-ivan.md`, with the screenshots and logs in the same folder.
2. Or send the filled-in file, with the screenshots and logs, to the team.

Fill in each row like this:

- Pass/fail: `pass`, `fail`, or `skipped` with the reason in the notes.
- Time taken: the wall-clock time of the step, for example `6 min 20 s`.
- Notes: for a failure, the first line that differs from the expected result.
- Screenshot/log: the file name of a screenshot or saved terminal output, if you took one.

About this test run:

- Tester:
- Date:
- Commit tested (`git log --oneline -1`):
- Operating system and version:
- Docker version and memory setting:
- Browser and version:
