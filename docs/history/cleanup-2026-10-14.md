# Review and clean-up of 2026-10-14

Planned for the night of 2026-10-14 and done on 2026-10-16 on branch `nikunj/ps02-cleanup`, from `main` at
`120e001`. It has two parts: a review of the 14 commits `654523d..120e001`, and a clean-up of the whole repository
to remove repeated text and reduce its size. Product behaviour is unchanged apart from the one fix below.

## Review of `654523d..120e001`

The review looked hardest at the limited fetch and the JSON-LD context loader in `packages/formats`, the Obsrv
telemetry (`GET /api/telemetry/obsrv` and the optional push), and the Mimoto login change in
`deploy/inji-stack/compose.yaml`.

- **Fixed:** `fetchLimited` checked the host of any URL a credential named. A `file:`, `data:` or `ftp:` URL went on
  to a DNS lookup or to the caller's fetch, then failed late with a message about a private address. It now refuses
  every scheme except http and https before any lookup or request, with the caller's "insecure" code. The test
  `limited fetch: URL schemes` fails without the fix.
- **Checked, no change needed:**
  - IPv4-mapped, NAT64, 6to4 and Teredo addresses carrying a private IPv4 address are refused, as are hex and
    short forms of 127.0.0.1. Node's `BlockList` matches mapped addresses against the IPv4 rules.
  - The pinned connection keeps the host name for the TLS server name and the `Host` header. No redirects are
    followed on either path.
  - Both of the context loader's caches stop at 200 documents. The compose-network context hosts are allowed for
    the loader only, not for did:web documents or status lists.
  - The telemetry endpoint takes the same filters as `/api/metrics`. The push runs only when `PLAYGROUND_OBSRV_URL`
    is set, and waits for pending pushes on shutdown.
  - Mimoto's sign-in client is public (`none`), and the test authorization server requires PKCE S256, a registered
    redirect URI and the same redirect URI at the token endpoint.
- **Not changed:** documentation-only address ranges such as 192.0.2.0/24 and 2001:db8::/32 are not refused. They
  are not routed on the internet, so they cannot reach a private service.
